# 載せる

手元の PDF に、文字と白い矩形を上から足して書き出すツールです。画面のプレビューと書き出しはどちらも PyMuPDF で描くので、クリックした位置がファイル上の位置になります。元の PDF は変更しません。書き出しファイルは `元の名前-追記.pdf` です。

サーバーは `127.0.0.1` だけで待ち受けます。PDF はメモリ上に置き、外部へは送りません。

## 必要なもの

- macOS（ヒラギノ明朝 ProN）
- Python 3.10 以降

文字はヒラギノ明朝 ProN で描きます。次のいずれかに、ファイル名が `明朝 ProN.ttc` で終わるフォントが必要です。

- `/System/Library/Fonts`
- `/System/Library/Fonts/Supplemental`
- `~/Library/Fonts`

## 起動

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 app.py
```

ブラウザで http://127.0.0.1:8734/ が開きます。止めるときは Ctrl+C です。

## 使い方

1. 「PDFを開く」を押すか、ウィンドウへ PDF をドロップする。
2. ページ上をクリックして文字を置く。クリック位置は、1行目のベースライン左端です。
3. 入りきらない元の文字は、「白で隠す」でドラッグして覆う。
4. 「書き出す」で追記済みの PDF を保存する。

文字の大きさは 6〜32 ポイント、0.5 刻みです。初期値は 10 ポイントです。改行はそのまま複数行になります。行送りは文字サイズの 1.15 倍です。

白い矩形や文字がフォーム欄に重なると、その欄は書き出し時に非表示になります。欄の値そのものは残します。重なっていない欄はそのままです。

開ける PDF は 40MB までです。パスワードが必要な PDF は、空のパスワードで開けるものだけ扱えます。

## 操作

| キー | 動作 |
| --- | --- |
| T | 文字を置く |
| W | 白で隠す |
| 矢印 | 選択中のものを 0.5 ポイント動かす |
| Shift + 矢印 | 5 ポイント動かす |
| Delete / Backspace | 選択中のものを消す |
| Esc | 選択を外す |
| ⌘Z / Ctrl+Z | 戻す |
| ⇧⌘Z / Ctrl+Shift+Z / Ctrl+Y | やり直す |

表示倍率は 100%、150%、200% です。位置の数値はポイントで、ページ左上を原点にします。文字の上下位置は、1行目のベースラインです。

## 動作確認

```bash
python3 app.py --check
```

フォントの読み込み、座標の向き、文字の書き出し、覆ったフォーム欄だけを隠す処理を確認します。成功すると `self-check ok` と表示します。

## 構成

```
app.py            サーバーと PDF の描画
static/           画面（HTML / CSS / JS）
requirements.txt  pymupdf
```
